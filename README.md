# dna-sequence-analyzer

A Python program that takes a DNA sequence and calculates base counts,
GC content, the reverse complement, and the translated protein sequence.

Built using Python functions, dictionaries and string handling.

## How to run

Run the program in Google Colab or any Python environment, then enter a DNA sequence when prompted.

## Example

Input: ATGGCCATTGTAATGGGCCGCTGAAAGGGTGCCCGATAG

Output:
- GC content: 56.4%
- Protein: MAIVMGR
